# DemoSpread (Gradle)

Aplicação de demonstração da API Java do Spread 5.0.1. Requisitos: JDK 21 ou superior e Gradle.

A biblioteca do Spread não está no Maven Central: `libs/spread-5.0.1.jar` é incluída no projeto e referida diretamente no `build.gradle.kts`. Instruções completas em `/labs/lab07-spread/Laboratorio-Spread.md`.
